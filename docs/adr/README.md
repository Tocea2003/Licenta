# Architecture Decision Records

Deciziile de arhitectură ale proiectului TURSIB Digital Twin, în formatul lui Michael Nygard
(context, decizie, consecințe). Un ADR nu se rescrie după ce e acceptat; o decizie nouă îl
înlocuiește și îl marchează „Superseded”.

| Nr. | Titlu | Stare |
|---|---|---|

| [002](002-signalr-with-firebase-fallback.md) | SignalR pentru harta live, Firebase ca rezervă | Acceptat |
| [003](003-sampled-position-history.md) | Istoric de poziții eșantionat în PostgreSQL | Acceptat |
